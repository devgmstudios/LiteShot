Why you can trust it

Checked on VirusTotal

VirusTotal runs a file past 70+ antivirus engines. The links above open the report for these exact files, matched by their SHA-256.

Open source, MIT

Every line of LiteShot, its update server and fortefile.com is public. Build it yourself if you like.

Signed updates

Each release is signed by Devgm, LLC; LiteShot refuses any update whose signature or SHA-256 doesn't match.

No telemetry

No accounts, no analytics, no ads. Nothing leaves your PC unless you upload or use AI.

Check a download yourself

In PowerShell, compare the result with the SHA-256 above:

Get-FileHash .\LiteShot-Setup-1.1.2.msi

Windows says "unknown publisher"?

LiteShot isn't code-signed with a certificate yet, so SmartScreen may warn the first time. Choose More info › Run anyway, or check the file on VirusTotal first.

Requirements

Windows 10 (1809 or later) or Windows 11, 64-bit. About 200 MB of disk space. Everything LiteShot needs is included.
